# VantaFlow CRM Prototype

A single-file desktop CRM interface prototype for ultra-wide monitors.

## Run locally

Open `index.html` directly in a browser. No build step or dependencies are required.

## Included pages

- Leads: detailed lead list, company workspace, financial analysis, communications, dialer, and mock files
- Messages: SMS, WhatsApp, call log, contacts, connected devices, and composer
- Email: inbox, reading view, compose modal, drafts, sent, archive, and trash navigation
- Scanner: mock extraction queue, progress, confidence, warnings, and conflicts
- Command: mock email/SMS campaigns with pacing, safety controls, progress, and live activity

All actions are visual prototype interactions; no real calls, messages, emails, scans, or campaign sends occur.
